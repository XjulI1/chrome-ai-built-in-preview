Configurer Brave Search API

Crée un compte sur api.search.brave.com, souscris au plan Free (2 000 requêtes/mois, gratuit en récurrent), puis copie ta clé API depuis le dashboard.

⚠️ Stockée localement (localStorage). Brave ne supportant pas CORS, les requêtes passent par un proxy local : lance node cors-proxy.js dans le même dossier que ce fichier.
